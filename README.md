# YoungZM Blog

Source code for [YoungZM](https://youngzm.com)'s Hugo-based blog: [blog.youngzm.com](https://blog.youngzm.com).

## Local development

Install Hugo Extended and use the version expected by the repository configuration. Start a local preview with the project’s Hugo command, then build the site before deployment.

~~~bash
hugo server
hugo
~~~

## Content and assets

- content contains blog posts and pages.
- static contains site assets.
- theme and configuration files define presentation and deployment behavior.

Review front matter, links, image paths, and generated output before publishing.
